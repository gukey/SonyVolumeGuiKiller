# 索尼电视音量弹窗管理工具：使用说明

![项目功能总览](images/project-overview.png)

## 下载与安装

- Windows 电脑：下载 `SonyVolumeGuiKiller-PC-1.0.4-win-x64.zip`，完整解压后运行 `SonyVolumeGuiKillerPcManager.exe`。程序自带 .NET 运行环境和 ADB，适用于 64 位 Windows；请保留旁边的 apk 文件夹。
- 电视：`SonyVolumeGuiKiller-1.0.4-debug.apk` 是电视守护应用，不是在电脑运行的文件。可由 PC 工具安装到电视。
- 工具包已包含 1.0.4 守护 APK，自动 5555 辅助 APK 作为 EXE 资源打包。配置完成后电脑可以关闭，电视上的服务继续工作。

## 工具主界面

![Windows 工具演示界面](images/tool-main.png)

截图使用示例数据；左侧填写 IP 并点击连接，上方三个输入框按以下图解填写。连接后可备份安装包、安装/更新和诊断。

## 三个输入框怎么填

![三个输入框填写图解](images/connection-guide.png)

| 输入框 | 在电视哪里找 | 用途 |
| --- | --- | --- |
| ① 配对端口 | 无线调试 → 使用配对码配对设备 → 弹窗中的 IP 地址与端口，取冒号后的数字 | 首次无线配对 |
| ② 六位配对码 | 同一配对弹窗的六位数字，保留开头的 0 | 验证此次配对；不是端口 |
| ③ 调试端口 | 无线调试主页面中的 IP 地址与端口，取冒号后的数字 | 配对后连接、安装及诊断 |

1. 电脑和电视接入同一局域网，打开电视的开发者选项和无线调试。
2. 先记下主页面的调试端口，再进入配对弹窗。
3. 保持配对弹窗打开，按上表填入三项；在工具左侧填写电视 IP，不带端口。
4. 点击左侧“连接电视”。如有电视授权弹窗，请确认允许电脑调试。
5. 配对失败时重新打开弹窗，使用新的端口和配对码。图中的数字仅是示例，不要照填。

已配对过：①②一起留空，③填当前调试端口。已开启固定网络 ADB：①②留空，③可填 5555。无线调试的动态端口可能变化；5555 并非所有电视默认开启。

EXE 连接区域的“这三项怎么填？查看图解”和左侧“说明”都能打开图文帮助；“这个项目做什么”标签展示功能总览。

## 安装与检查

连接后先备份旧 APK，再执行安装/更新。确认无障碍服务已启用、本机 ADB 授权文件有效，并检查页面的最近成功时间与拦截状态。守护成功时 `mVolumeController` 应为空。

旧 APK 若与新版签名不同，Android 会拒绝覆盖安装。**请先备份应用私有授权文件和配置，不要直接卸载。** 工具里的“备份电视 APK”仅备份安装包，不等于备份授权文件。

PC 诊断中的无障碍状态目前可能误判；若显示 disabled，而电视 App 报告已连接，请同时核对电视无障碍设置。此轮修改未重写 PC 诊断逻辑。

## 适用范围与验证

本项目隐藏兼容索尼 Android TV 上的系统音量弹窗，不锁定音量、不静音。需要有效的无障碍和 ADB 授权，无法保证全部型号与固件兼容。

APK 已在 BRAVIA 4K AE2 / Android 14 上验证音量键、授权文件异常恢复、重新绑定、短暂待机唤醒及返回桌面后的检查；尚未完成多日稳定性验证。

Windows 工具已完成 Release 构建、窗口加载及常规/最小尺寸渲染检查，帮助图文资源可离线加载。本次没有重新执行电视一键安装。

连接机制参考：[Android 官方 ADB 说明](https://developer.android.com/tools/adb)。

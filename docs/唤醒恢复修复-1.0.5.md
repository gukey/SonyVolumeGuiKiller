# 音量应用 1.0.5：待机唤醒恢复

日期：2026-10-23。设备：192.168.1.111，Sony BRAVIA 4K AE2。

用户报告待机唤醒后音量菜单偶尔闪现，随后消失。原版唤醒仅触发一次即时检查，成功后恢复五秒周期；无法覆盖系统稍后重新注册音量控制器的整个过程。这是代码中的恢复窗口缺口，但本次未捕获原版闪现瞬间，不能认定它是唯一原因。

1.0.5 / versionCode 6 在服务连接及唤醒后进入三十秒恢复窗口，完成一次操作后等待三百毫秒再次检查；成功不会提前退出窗口。窗口内单次 ADB 操作限时一千五百毫秒，避免长时间卡在旧连接。唤醒会关闭在途连接，完成后立即执行待处理检查。音量键及 SystemUI 窗口事件立即请求检查。窗口外保留五秒周期和失败退避。

三百毫秒是操作完成后的等待时间，不是菜单可见时间上限；ADB 认证、系统调度及恢复本身仍需时间。这项修复不能保证开屏第一帧或 ADB 完全不可用时没有菜单闪现。
